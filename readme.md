# Decision Tree Fruit Prediction 🍎🍊

## About This Project
This is a simple Machine Learning project where I used a Decision Tree Classifier to predict fruits based on their weight and color.

I trained the model using a small dataset of apples and oranges.

## Technologies Used
- Python
- Scikit-learn
- Matplotlib

## Features
- Predicts whether a fruit is an apple or orange.
- Uses weight and color as input features.
- Trains a Decision Tree Classifier.
- Visualizes the decision tree using Matplotlib.

## How to Run
 Clone this repository:

```bash
git clone https://github.com/jayprakashbiswa49-pixel/First-ML-Model
```

Run the Python file:

```bash
python fruit_prediction.py
```

## Sample Predictions

- Weight: 160g, Color: Red → Apple
- Weight: 115g, Color: Orange → Orange
